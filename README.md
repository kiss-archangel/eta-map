# ETA Map

Сайт: час підльоту цілей до об'єктів на карті Рівненської області.

Режими:
- **Ручний**: особиста пісочниця, дані зберігаються лише у вашому браузері.
- **Авто**: стан тривог по області з Ukraine Alarm API (ключ вводиться на сторінці).
- **Спільна**: адміністратор ставить цілі й об'єкти на карті, усі відвідувачі бачать їх одночасно.

Ключі API у репозиторії не зберігаються.

## Як увімкнути режим «Спільна» (Firebase, безкоштовно)

1. Відкрийте https://console.firebase.google.com, **Add project**, назва довільна, Google Analytics можна вимкнути.
2. **Build → Realtime Database → Create database**. Оберіть регіон (наприклад, europe-west1) і запуск у **locked mode**.
3. **Build → Authentication → Get started → Email/Password → Enable**.
4. У вкладці **Users** натисніть **Add user**: введіть email і пароль адміністратора. Скопіюйте його **User UID**.
5. У **Realtime Database → Rules** вставте правила (підставте свій UID) і натисніть **Publish**:

```
{
  "rules": {
    "eta": {
      ".read": true,
      ".write": "auth != null && auth.uid === 'ВАШ_UID'"
    }
  }
}
```

6. **Authentication → Settings → User actions**: зніміть позначку «Enable create (sign-up)», щоб ніхто сторонній не міг зареєструватись.
7. **Authentication → Settings → Authorized domains → Add domain**: додайте `ВАШ_ЛОГІН.github.io`.
8. **Project settings (шестерня) → General → Your apps → Web (</>)**: зареєструйте застосунок і скопіюйте об'єкт `firebaseConfig`.
9. Відкрийте файл `firebase-config.js` у цьому репозиторії (олівець Edit), розкоментуйте поля й вставте свої значення, особливо `databaseURL`. Натисніть **Commit changes**.
10. Зачекайте 1–2 хвилини й відкрийте сайт. У режимі «Спільна» розкрийте «Вхід для адміністратора» і увійдіть. Усі інші бачитимуть дані без входу.

Читати дані може будь-хто, хто знає адресу сайту. Писати може тільки обліковий запис із вашим UID. Не публікуйте на карті точні позиції військових чи критичних об'єктів.
